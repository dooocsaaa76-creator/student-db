학생 DB 관리

재원생 관리

· 새 배치생 리스트를 올리면 같은 ID 학생의 연락처·메모는 그대로 유지되고, 명단에서 빠진 학생은 퇴원생으로 이동합니다. 한 학생이 여러 클래스를 들으면 한 명으로 합쳐 표시합니다.
· 연락처 일괄 업로드: '연락처 미입력 명단'에 연락처를 채워 다시 올리면 ID 기준으로 반영됩니다. (빈 칸은 기존 값을 지우지 않습니다)
· 표에서 연락처·메모를 입력하고 칸을 벗어나면 바로 저장됩니다.

퇴원생 관리

외부생 DB 업로드

· '학년 기준 연도'는 업로드하는 파일의 학년이 몇 년도 기준인지 입력합니다. 해가 바뀌면 학년이 자동으로 올라갑니다 (설정에서 끌 수 있음).
· 열 이름에 '학년', '지역'(또는 주소·거주지)이 있으면 자동 인식합니다. 그 외 열은 그대로 보존되어 다운로드됩니다. 이름+연락처가 같은 행은 중복으로 보고 제외합니다.

문자 수신거부 등록

문자를 보내지 말아달라고 요청한 연락처를 등록하면 외부생 DB·퇴원생 다운로드에서 항상 제외됩니다. 외부생 DB를 새로 올려도 계속 제외됩니다.

접근 권한 관리

여기에 등록된 이메일 계정만 로그인할 수 있습니다. 추가하면 초기 비밀번호 로 계정이 만들어지고, 첫 로그인 때 비밀번호를 반드시 변경해야 합니다.

    백업 / 복원

    데이터는 Firebase에 저장되어 어느 PC에서든 로그인하면 같은 내용이 보입니다. 만일을 대비해 가끔 백업 파일을 받아 두세요.
    이전에 쓰던 '학생DB관리.html'(PC 저장 버전)의 백업 파일도 '불러오기'로 그대로 옮겨올 수 있습니다.
