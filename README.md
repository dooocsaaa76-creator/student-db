# 학생 DB 관리

재원생·퇴원생·외부생 DB를 관리하는 웹페이지입니다.

- **저장소**: Firebase Firestore (프로젝트 `cms-student-db`, 서울 리전)
- **웹페이지 호스팅**: GitHub Pages (GitHub에 파일을 올리면 1~2분 뒤 자동 반영)
- **접근 제한**: 관리자가 미리 등록한 이메일 계정만 로그인 가능 (초기 비밀번호 `123456`, 첫 로그인 때 변경 필수)

> ⚠ 학생 명단 엑셀(`*.xlsx`)과 백업 파일(`*.json`)은 `.gitignore`로 막아 두었습니다. GitHub 저장소에는 **프로그램 파일만** 올라가고, 학생 데이터는 Firebase에만 저장됩니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구성 |
| `styles.css` | 디자인 |
| `app.js` | 업로드·퇴원 처리·학년 진급·외부생 필터 등 기능 |
| `store-firebase.js` | Firebase 저장/불러오기, 로그인 |
| `firebase-config.js` | Firebase 프로젝트 연결 정보 (공개되어도 괜찮은 값) |
| `firestore.rules` | 데이터 접근 규칙 (허용된 계정만 읽기/쓰기) |

## 처음 한 번만 하는 설정

### 1. 이메일/비밀번호 로그인 켜기
1. https://console.firebase.google.com/project/cms-student-db/authentication 접속
2. **시작하기** → **로그인 방법(Sign-in method)** 탭 → **이메일/비밀번호** 선택 → 첫 번째 스위치 **사용 설정** → **저장**

### 2. 첫 관리자 계정 등록
계정 관리 화면도 로그인 후에만 쓸 수 있으므로, **최초 1명은 콘솔에서 직접 등록**합니다.
1. **로그인 계정 만들기**: https://console.firebase.google.com/project/cms-student-db/authentication/users → **사용자 추가** → 이메일, 비밀번호 `123456` 입력 → 추가
2. **허용 목록 등록**: https://console.firebase.google.com/project/cms-student-db/firestore/databases/-default-/data → **컬렉션 시작** → 컬렉션 ID: `allowedUsers`
   - **문서 ID**: 1번의 이메일을 **소문자로** 입력 (예: `teacher@gmail.com`)
   - 필드 `name` (문자열) = 본인 이름
   - 필드 `mustChange` (불리언) = `true` → **저장**
3. 웹페이지에서 로그인하면 비밀번호 변경 화면이 나옵니다. 새 비밀번호로 바꾸면 사용할 수 있습니다.

### 3. GitHub Pages 켜기
1. GitHub 저장소 → **Settings** → 왼쪽 **Pages**
2. **Source**: `Deploy from a branch` / **Branch**: `main`, 폴더 `/ (root)` → **Save**
3. 1~2분 뒤 표시되는 주소(`https://아이디.github.io/저장소이름/`)가 웹페이지 주소입니다.

## 계정 관리 (미리 등록한 이메일만 접속)

- **[백업 · 설정] 탭 → 접근 권한 관리**에서 이메일을 추가하면 **초기 비밀번호 `123456`** 으로 로그인 계정이 만들어집니다.
- 처음 로그인하면 **비밀번호 변경 화면**이 나오고, 변경 전에는 학생 DB를 볼 수 없습니다.
- 비밀번호를 잊은 경우: 로그인 화면의 '비밀번호를 잊으셨나요?' 또는 관리 화면의 '비밀번호 재설정 메일' → 메일의 링크로 새 비밀번호 설정
- 목록에서 **삭제**하면 그 계정은 로그인해도 학생 DB에 접근할 수 없습니다.
- 등록되지 않은 이메일은 계정이 있어도 "접근 권한이 없습니다"로 막힙니다.

> 초기 비밀번호는 저장소 코드에 공개되어 있으므로, 계정을 추가한 뒤에는 해당 선생님이 **바로 로그인해서 비밀번호를 바꾸도록** 안내해 주세요. 관리 목록에 "초기 비밀번호 미변경" 표시가 남아 있는 계정은 아직 바꾸지 않은 계정입니다.

## 외부생 DB

- MG 추출 파일 형식(`std_id`, `std_name`, `std_grade_type`, `std_guardian1_tel`, `saddr_si`, `saddr_gu` … 또는 `ID`, `이름`, `학교`, `학년`, `학부모 연락처` …)을 그대로 올리면 됩니다.
  영문·한글 열 이름이 달라도 **ID · 이름 · 학교 · 학년 · 학부모 연락처 · 상태 · 시도 · 시군구 · 동 · 주소** 표준 열로 통일됩니다.
- 지역은 `시도 + 시군구`로 인식합니다 (예: `서울특별시`/`서울` + `서초구` → `서울 서초구`). 시도·시군구가 비어 있으면 주소에서 찾습니다.
- 같은 학생 ID는 중복으로 보고 한 번만 저장합니다. (ID가 없는 파일은 이름+연락처 기준)
- **권역 버튼**: 대치 / 서초 / 관악 / 목동 / 평촌 / 마포 (MG 권역표 기준, 수원시·안양시는 시 전체)
- **같은 연락처는 1건만**: 형제가 학부모 번호를 같이 쓰는 경우 문자가 중복으로 가지 않도록 한 번만 다운로드
- 외부생 DB는 용량이 커서 **외부생 DB 탭을 열 때** 불러옵니다.

## 문자 수신거부

- [수신거부] 탭에서 번호를 등록하거나, 외부생 결과 표의 [수신거부] 버튼으로 바로 등록합니다.
- 등록된 번호는 **외부생 DB 다운로드와 퇴원생 목록/다운로드에서 항상 제외**됩니다. 외부생 DB를 새로 올려도 계속 제외됩니다.
- 재원생·퇴원생 표에는 이름 옆에 `수신거부` 표시가 붙습니다.
- 잘못 등록했으면 [수신거부] 탭에서 **해제**하면 됩니다.

## 웹페이지 수정(업데이트) 방법

- 수정한 파일을 GitHub 저장소에 올리면(커밋/푸시) 1~2분 뒤 웹페이지에 자동 반영됩니다.
- GitHub 웹사이트에서 직접 올릴 때: 저장소 → **Add file → Upload files** → 수정한 파일 끌어다 놓기 → **Commit changes**
- 화면이 바로 안 바뀌면 브라우저에서 `Ctrl + F5`(강력 새로고침)를 눌러 주세요.
- 학생 데이터는 Firebase에 있으므로 웹페이지를 수정해도 데이터는 그대로 유지됩니다.

### 접근 규칙(firestore.rules)을 바꿨을 때
규칙은 GitHub가 아니라 Firebase에 따로 반영해야 합니다. 이 폴더에서:
```
firebase deploy --only firestore:rules
```

## 이전 버전(PC 저장용 `학생DB관리.html`) 데이터 옮기기
1. 이전 `학생DB관리.html` → [백업 · 설정] → **백업 파일 저장**
2. 새 웹페이지 로그인 → [백업 · 설정] → **백업 파일 불러오기** → 받은 `.json` 선택

## 데이터 구조 (Firestore)

| 위치 | 내용 |
|---|---|
| `students/{학생ID}` | 재원생·퇴원생 (`status`: `active` / `withdrawn`), 연락처·메모·학년·클래스 등 |
| `externalChunks/*` | 외부생 DB (여러 행을 묶어서 저장) |
| `meta/main` | 설정, 최근 업로드 정보 |
| `meta/external` | 외부생 DB 열 목록 |
| `optOut/{숫자만 연락처}` | 문자 수신거부 번호 |
| `logs/*` | 작업 이력 |
| `allowedUsers/{이메일}` | 접근 허용 계정 (`mustChange`: 초기 비밀번호 미변경 여부) |

배치생 리스트를 올릴 때는 학생 문서에 **연락처·메모 칸을 아예 건드리지 않는 방식(merge)** 으로 저장하므로, 같은 ID 학생의 연락처는 절대 지워지지 않습니다.
